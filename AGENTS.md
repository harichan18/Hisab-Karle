## MCP Tool Usage Instructions

When working on this project, automatically use relevant, available MCP tools whenever they can improve accuracy or verification.

- **Context7:** Consult current official documentation for unfamiliar libraries, frameworks, APIs, or version-sensitive implementations.
- **GitHub:** Inspect repository files, history, issues, and pull requests when relevant to the task.
- **Chrome DevTools:** Investigate browser console errors, network failures, and frontend performance problems.
- **Playwright:** Run browser-based tests and verify user workflows when applicable.
- **Firecrawl:** Gather information from permitted public websites when web research is needed.
- **Sentry:** Investigate relevant application errors and performance issues when authenticated and available.
- **Google Cloud MCP tools:** Use only for tasks relevant to their supported cloud, notebook, data, or visualization capabilities.

Use only tools that are relevant to the current task. Do not call every tool for every request.

Prefer official documentation, inspect existing code before editing, and verify changes with appropriate tests. If a required MCP server is unavailable, report that limitation rather than pretending the tool was used.

Ask for approval before destructive changes, production operations, or actions that expose private data or incur costs.
